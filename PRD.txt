# YouTube Subtitle Timeline Generator: Product Requirements Document (MVP)

## 1. Project Overview

### 1.1 Project Title
YouTube Subtitle Timeline Generator

### 1.2 Objective
Develop a web application that enables users to paste a YouTube URL, automatically fetch and extract available subtitles, parse the subtitle data, and generate an interactive timeline. This timeline will allow users to quickly navigate to key segments of the video through clickable time markers.

### 1.3 Key Benefits
- **Time Savings**: Quickly jump to relevant parts of lengthy videos
- **Enhanced Accessibility**: Improve content comprehension and searchability
- **Content Navigation**: Facilitate direct access to video segments without manual scrubbing
- **Subtitle Format Flexibility**: Let users choose from available subtitle formats (e.g., SRT, VTT) for viewing and export

## 2. Project Scope

### 2.1 In Scope

#### Core Functionality
- URL input and validation
- Subtitle retrieval via integration with YouTube's API using Next.js backend routes
- Subtitle parsing to create a structured timeline of timestamps
- Interactive timeline visualization integrated with an embedded YouTube player
- User choice for subtitle formats during retrieval and export
- Basic error handling and user notifications

#### User Interface & User Experience
- Clean, responsive UI design leveraging Next.js front-end
- Export functionality to download the timeline in various formats (e.g., TXT, PDF)

### 2.2 Out of Scope (for MVP)
- Advanced NLP chapter detection
- Multi-language subtitle processing beyond a single language per request
- In-depth analytics or user profiles
- Advanced sharing/integration features with third-party platforms
- Any persistent storage (no database required) as we host on Vercel

## 3. Functional Requirements

### 3.1 User Input & Validation

#### URL Input Field
- Users paste a YouTube URL
- Validate URL format and confirm it is a valid YouTube link
- Display clear error messages for invalid or unsupported URLs

#### Pre-Processing Checks
- Verify that the provided video contains subtitles
- Inform users if subtitles are missing or unavailable

### 3.2 Subtitle Retrieval

#### YouTube API Integration
- Use Next.js backend routes to securely interact with YouTube's API
- Fetch the available subtitle files for the provided video

#### Subtitle Format Options
- Detect available subtitle formats (e.g., SRT, VTT)
- Present users with a choice to select their preferred subtitle format

#### Error Handling
- Display user-friendly error messages for any subtitle retrieval issues
- Log and monitor errors within the Next.js backend for diagnostics

### 3.3 Subtitle Parsing & Timeline Generation

#### Data Extraction
- Parse the downloaded subtitle file to extract timestamps and text segments

#### Timeline Creation
- Automatically generate a structured timeline with key time markers
- Provide an option to group subtitles into chapters based on fixed time intervals

#### Algorithm Flexibility
- Ensure the parsing module robustly handles both manually provided and auto-generated subtitles

### 3.4 Interactive Timeline & Video Playback

#### Timeline Display
- Visually represent the timeline as clickable markers
- Show associated subtitle text with each time segment in an organized manner

#### YouTube Player Integration
- Embed a YouTube player that synchronizes with the timeline
- Clicking a timeline marker should jump the video playback to the corresponding timestamp

### 3.5 Export & Sharing Functionality

#### Export Options
- Allow users to download the generated timeline in preferred formats (e.g., TXT, PDF)
- Provide subtitle format choices on export if multiple formats are available

#### Sharing Options
- Optional for MVP: Consider adding functionality for sharing a link to the generated timeline

## 4. Non-Functional Requirements

### 4.1 Performance & Scalability

#### Response Time
- Aim for a process time of only a few seconds from URL submission to timeline generation

#### Concurrent Requests
- Leverage Next.js serverless functions to handle concurrent requests efficiently without a dedicated database

### 4.2 Usability & Accessibility

#### Responsive Design
- Ensure the application is optimized for desktops, tablets, and mobile devices

#### User Interface
- Build an intuitive, minimalistic interface using Next.js, focusing on ease of use

#### Accessibility
- Follow WCAG guidelines to support users with disabilities

### 4.3 Security & Compliance

#### Data Security
- Securely manage API keys within the Next.js environment using environment variables

#### Compliance
- Comply with YouTube's API and content usage policies

#### Input Sanitization
- Sanitize all user inputs to prevent injection attacks and maintain application integrity

### 4.4 Reliability & Maintainability

#### Error Logging
- Implement logging within Next.js serverless functions to diagnose issues in subtitle retrieval or timeline generation

#### Modular Architecture
- Develop the application in a modular fashion to simplify future updates and maintenance

## 5. Technical Requirements

### 5.1 Architecture

#### Frontend
- **Framework**: Next.js for a React-based, server-rendered front-end
- **UI Components**: 
  - URL input and validation
  - Subtitle format selection
  - Interactive timeline display
  - Embedded YouTube player integration (using YouTube's embed API)

#### Backend
- **Platform**: Next.js API routes for backend processing
- **API Integration**: Securely integrate with YouTube's API to retrieve subtitle information
- **Subtitle Processing Module**: Functions to parse and process subtitle files within the Next.js backend
- **No Database**: Use serverless functions for processing on-the-fly without persistent storage

#### Page Routes & Structure
- **Home Page** (`/`): Main landing page with URL input form and application introduction
- **Results Page** (`/results/[videoId]`): Displays the generated timeline and embedded player for a specific video
- **API Routes**:
  - `/api/validate`: Validates YouTube URLs and checks subtitle availability
  - `/api/subtitles/[videoId]`: Retrieves available subtitle formats for a video
  - `/api/subtitles/[videoId]/[format]`: Fetches and processes specific subtitle format
  - `/api/export/[videoId]/[format]`: Generates exportable timeline in requested format (TXT, PDF)
- **Error Page** (`/404`): Custom error page for invalid URLs or videos without subtitles
- **About Page** (`/about`): Information about the application, usage instructions, and FAQs

### 5.2 Infrastructure & Deployment

#### Hosting Environment
- Deploy the application on Vercel, leveraging serverless functions and global CDN

#### CI/CD
- Utilize Vercel's built-in continuous deployment to push updates automatically from the code repository

### 5.3 Development Stack

- **Frontend**: Next.js, React, CSS/Tailwind CSS
- **Backend**: Next.js API routes (Node.js)
- **APIs**: YouTube Data API, YouTube Player API
- **Deployment**: Vercel

## 6. User Journey

1. User visits the application landing page
2. User pastes a YouTube URL in the input field
3. System validates the URL and checks for subtitle availability
4. If subtitles are available, system presents available subtitle format options
5. User selects preferred subtitle format
6. System retrieves and processes the subtitles
7. System generates and displays the interactive timeline alongside the embedded YouTube player
8. User can click on timeline markers to navigate through the video
9. User can export the generated timeline in their preferred format

## 7. Success Criteria

1. Users can successfully extract subtitles from at least 95% of YouTube videos with available captions
2. Timeline navigation accurately jumps to correct video timestamps
3. Processing time is under 3 seconds for videos up to 15 minutes in length
4. The application functions correctly across all major browsers and devices
5. Users can successfully export the timeline in at least two different formats

## 9. Key Risks & Mitigation

| Risk | Impact | Mitigation Strategy |
|------|--------|---------------------|
| YouTube API limitations/changes | High | Monitor API documentation, implement caching where possible, have fallback methods |
| Subtitle format inconsistencies | Medium | Test with diverse subtitle formats, build robust parsing logic with error handling |
| Performance issues with longer videos | Medium | Implement chunked processing, optimize timeline rendering |
| Browser compatibility issues | Medium | Test across major browsers, use widely supported web technologies |
